A PRACTICAL START

How to get started with NotebookLM.

  1. Create a notebook and add relevant sources supported by the current interface.
  2. Ask specific questions about the supplied material and inspect citations or source references.
  3. Use the output to build study notes or an outline, then confirm critical details in the original documents.
CHECK BEFORE YOU COMMIT

Important limits to check.

  • Supported source types, limits, and generated features can change by account and region.
  • Source-grounded answers can still misread or omit context; check the original passage.
  • Do not upload confidential or sensitive documents without checking permissions and privacy requirements.
